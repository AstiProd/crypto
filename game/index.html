Atelier de foreuses

Achète une foreuse Mk-I et pose-la sur un socle libre. Fusionne deux foreuses identiques pour monter d'un rang.

Améliorations

Astro Base Tycoon

Kepler-442 b — an 2187.

  1. Déplace l'astronaute : joystick (mobile) ou ZQSD / WASD / flèches.
  2. Ramasse les cristaux sous les foreuses, ils s'empilent sur ton dos.
  3. Dépose-les à la raffinerie, récupère les puces de crédit.
  4. Encaisse au terminal pour convertir en crédits ◈.
  5. Reste sur un socle verrouillé pour l'acheter, puis glisse une foreuse sur une autre du même rang pour fusionner.
